# Math Mania
An educational Android application featuring interactive math practice levels and handwritten digit recognition using TensorFlow Lite.

## About the Project
Math Mania is an educational Android application designed to help children ages 6-12 practice their math skills. The app combines math practice with handwritten input, allowing children to draw their answers directly on the screen and practice their handwriting.
## Features
- Three levels of math practice:
  - Addition and subtraction
  - Multiplication and division
  - Simple algebra
- Handwritten answer digit recognition using TensorFlow Lite 
- 30-second countdown timer for each question
- Immediate feedback based on user answers
- Audio feedback for winning and losing the game 
- Child-friendly Android interface
- Directions, victory, and game-over screens
## Technologies
- Java → Application logic and game functionality
- XML → Android user interface layouts
- Android Studio → Application development
- TensorFlow Lite → On-device handwritten digit recognition
- MNIST → Dataset used to train the digit recognition model
- GitHub → Version control and collaborative development
## How it works
1. The user selects a math level from the main menu.
2. A math problem is presented to the user.
3. The user draws their numeric answer directly on the screen.
4. The drawing is captured and processed as an image.
5. The TensorFlow Lite model analyzes the handwritten input.
6. The predicted digit is compared with the correct answer.
7. The user receives feedback and either continues to the next level or reaches the game-over screen.
